# Куда пойти в Пекине

Личная карта мест для поездки. Статический сайт: ни сервера, ни регистрации, ни баз данных.

**Что внутри**
- Живая векторная карта (MapLibre GL и бесплатные тайлы OpenFreeMap на данных OpenStreetMap), стили «Карта», «Светлая», «Тёмная» и обычная схема OSM.
- 24 места по категориям, поиск, фильтры, отметка «Был здесь».
- Кнопка «Где я» (определение местоположения), расстояния до дома и до вас.
- Кнопки «В Amap», «Apple Maps» и «Маршрут» (общественный транспорт в Apple Maps).
- Работает как приложение: можно добавить на экран «Домой». Карты, которые вы уже смотрели, остаются доступными без интернета.
- Все библиотеки лежат внутри папки `vendor`, внешние скрипты не подключаются.

## Как выложить на GitHub Pages

1. Зарегистрируйтесь на github.com и нажмите **New repository**. Название, например, `beijing-map`, доступ **Public**. Нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**.
3. Перетащите **содержимое** папки (файлы `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `.nojekyll` и папки `data`, `icons`, `vendor`), а не саму папку. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/beijing-map/`.

## Как добавить на экран «Домой» (iPhone)

Откройте адрес сайта в Safari, нажмите «Поделиться», затем «На экран "Домой"».

## Дом и университет

Адрес проживания не лежит в репозитории, потому что репозиторий для Pages публичный. Есть два способа:

- **Долгое нажатие на карте** (на компьютере правая кнопка мыши) → «Здесь я живу» или «Университет Кати». Точки сохраняются только в вашем браузере.
- **Файл `main.json`** (лежит рядом с архивом). Если вам не жалко, что адрес отеля будет виден всем, у кого есть ссылка, положите его в папку `data` в репозитории. Тогда обе точки появятся сразу у всех, кто откроет сайт.

## Как обновить места

Откройте `data/places.json` на GitHub (значок карандаша), измените или добавьте место и нажмите **Commit changes**. Координаты в нём в системе GCJ-02, как у Amap и Apple Maps. На карту они ложатся правильно, пересчёт делает сайт сам.
